# AI 参考图库中文版

为 AI 绘画、角色设计和漫剧分镜挑选参考图。这里有**服装、脸型、姿势、深度和二次元**五个图库，可按中文关键词或编号查找，打开大图后复制或下载所需素材。

## 选哪个图库？

| 图库 | 适合找什么 | 收录 | 在线入口 |
| --- | --- | --- | --- |
| [服装库](#costume-library) | 不含人物的衣装搭配、颜色、材质 | 写实 1,407 套，动画 1,320 套 | [写实版](https://deeyu.github.io/ai-costume-gallery-zh/) · [动画版](https://deeyu.github.io/ai-costume-gallery-zh/costume-anime/) |
| [脸型库](#portrait-library) | 虚构人物的五官、发型和整体造型 | 1,499 张参考图 | [打开脸型库](https://deeyu.github.io/ai-costume-gallery-zh/portrait/) |
| [姿势库](#pose-library) | 动作线稿、关节结构和构图视角 | 288 组、1,439 张线稿 | [打开姿势库](https://deeyu.github.io/ai-costume-gallery-zh/pose/) |
| [深度库](#depth-library) | 肢体遮挡、透视和空间远近 | 288 组、1,439 张深度图 | [打开深度库](https://deeyu.github.io/ai-costume-gallery-zh/depth/) |
| [二次元库](#anime-library) | 动漫发型、眼睛、衣装、姿势和英文标签 | 843 个基础条目 | [打开二次元库](https://deeyu.github.io/ai-costume-gallery-zh/anime/) |

**怎么取图？** 进入对应图库，选分类或输入关键词，点击卡片查看大图，再选择「复制图片」或下载。各库的搜索、筛选和图片格式见[使用指南](guide.md)。

## 图库预览

<a id="costume-library"></a>

### 服装库：按画风选衣装

写实版和动画版都可按季节、场合、颜色或材质查找。两个版本在服装库内切换，保留当前搜索词和分类。

![服装库：中文筛选与写实衣装参考](image/README/1793322085655.png)

<a id="portrait-library"></a>

### 脸型库：先看五官，再看整体造型

正面脸图 893 张，造型参考 606 张。可以按发长和发型筛选；原站下载排行每天同步，并标出最近成功同步时间。图中人物为 AI 生成的虚构人物，图片数不等于独立人物数。

![脸型库：正面脸图与发型参考](docs/portrait-desktop.png)

<a id="pose-library"></a>

### 姿势库：按动作和机位找线稿

适合绘画人体练习、动作教学和分镜构图。可按人物、动作和视角筛选，也可在同组姿势内切换正面、斜侧、侧面、俯视或仰视。

![姿势库：标准系人体线稿与多视角切换](docs/pose-desktop.png)

<a id="depth-library"></a>

### 深度库：观察前后关系与遮挡

灰度表示空间远近，白色越近、黑色越远。需要和姿势线稿配对时，查找相同的完整编号与视角。

![深度库：灰度深度图与多视角切换](docs/depth-desktop.png)

<a id="anime-library"></a>

### 二次元库：选角色外观或查英文标签

来自 CharaDB 公开版，包含发型与眼睛、服装和姿势。支持发色切换、姿势彩图与线稿切换，以及复制英文标签。843 个基础条目对应 1,027 张彩图（含发色变体）与 281 张姿势线稿。

![二次元库：节庆服装、中文名称与英文标签](docs/anime-overview.png)
